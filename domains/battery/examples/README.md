These are EXAMPLE documents, not data.

works the moment you clone the repository, and so the domain policy beside them

means anything about battery engineering -- see docs/ADDING_A_DOMAIN.md, which says
to calibrate against real documents before trusting any figure. Real documents
belong outside this tree: OPEN_DECISIONS D-08 settled that this repository is
public.
